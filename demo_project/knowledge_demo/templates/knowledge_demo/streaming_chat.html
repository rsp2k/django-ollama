How to Use This Demo
  1. Select Context Sources: Check the boxes for Articles, Documents, or Projects
  2. Configure Limits: Set how many items to include from each source
  3. Preview Context: Click "Preview Context" to see what will be sent to the AI
  4. Ask Questions: Type questions that relate to your selected context
  5. Watch Streaming: See AI responses appear in real-time with full context awareness
Note: This demo requires Ollama to be running. If you see AI errors, the service may be unavailable.
