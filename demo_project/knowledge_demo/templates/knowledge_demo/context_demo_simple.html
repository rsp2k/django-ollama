How It Works

  1. Middleware attaches lazy querysets to request
  2. Querysets remain unevaluated until needed
  3. AI serialization methods extract relevant data
  4. Context is filtered by user permissions

Key Features Demonstrated

🔄
Lazy Loading

Querysets are not evaluated until explicitly needed, maintaining Django's performance benefits.

🔐
Permission Aware

Context is automatically filtered based on user permissions and namespace access.

🎯
Priority Based

Higher priority querysets are processed first, ensuring most relevant context is available.

Technical Implementation

Core Concept: LazyQueryset
@dataclass
class LazyQueryset:
    name: str               # Identifier
    queryset: QuerySet      # Django queryset (not evaluated)
    ai_method: str         # Method to call for AI serialization
    limit: Optional[int]   # Max items to serialize
    priority: int          # Processing order
Middleware Integration
# In settings.py
MIDDLEWARE = [
    # ...
    'django_ollama.context_injection.AIContextMiddleware',
]
Usage in Views
from django_ollama.context_injection import get_ai_context

def my_view(request):
    # Get lazy querysets (not evaluated)
    lazy_context = get_ai_context(request, evaluate=False)

    # Evaluate for AI consumption
    ai_context = get_ai_context(request, evaluate=True)
