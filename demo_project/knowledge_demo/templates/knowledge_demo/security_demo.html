🛡️ Namespace Security Model

Django-Ollama implements a comprehensive security architecture:

  • Server-side validation: All namespace access is validated at the Django level
  • Permission integration: Leverages Django's user and group permissions
  • Zero-trust model: Explicit permission required for all namespace access
  • Audit logging: All access attempts are logged for security monitoring

🔍 Context Injection Security

How Django-Ollama secures AI context:

  • Lazy evaluation: Querysets aren't executed until needed
  • Permission filtering: Only accessible data included in context
  • Namespace isolation: Cross-namespace data leakage prevented
  • Request-scoped security: Permissions checked per request
# Example: Context automatically filtered by permissions @inject_querysets( lambda req: Article.objects.filter( namespace__in=get_user_namespaces(req.user) ) ) def ai_chat_view(request): # Only user's accessible articles included in AI context return render(request, 'chat.html')
